# Contributing to hcai-cli

`hcai-cli` is an agent-friendly command-line interface for Hack Club AI, providing access to LLM chat completions, text-to-speech, embeddings, and allowlisted Replicate proxy inference.

## Development Setup

Requirements: Node.js 20+ and npm.

```bash
# Clone
git clone https://github.com/Ahmet-Dedeler/hcai-cli.git
cd hcai-cli

# Install dependencies
npm install

# Build TypeScript
npm run build

# Link locally for testing
npm link
```

## How to Contribute

- Check [open issues](https://github.com/Ahmet-Dedeler/hcai-cli/issues) for starter tasks.
- PRs welcomed for streaming responses, new subcommands, audio playback integration, and enhanced JSON schema validation.
